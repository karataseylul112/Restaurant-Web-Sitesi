# 🍽️ Restourant Menu

HTML ve CSS kullanılarak geliştirilmiş, modern ve responsive bir restoran web sitesi projesidir.

## 📌 Proje Hakkında

Bu proje, web geliştirme alanındaki temel bilgilerimi geliştirmek ve HTML ile CSS kullanarak gerçek bir restoran web sitesi tasarlamak amacıyla hazırlanmıştır.

Web sitesinde restoranın ana sayfası, menü, ürünler, müşteri yorumları, iletişim, blog ve footer bölümleri bulunmaktadır.

## ✨ Özellikler

* 🏠 Ana sayfa
* 🍴 Restoran menüsü
* 🛍️ Ürün kartları
* ⭐ Müşteri yorumları
* 📍 İletişim bölümü
* 📝 Blog bölümü
* 🔎 Arama alanı
* 🛒 Sepet arayüzü
* 📱 Responsive tasarım

## 🛠️ Kullanılan Teknolojiler

* HTML5
* CSS3
* Font Awesome
* Google Fonts
